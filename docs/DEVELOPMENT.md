# 开发说明

## 结构

| 文件 | 职责 |
| --- | --- |
| `MainActivity.java` | 原生首页、设备管理、游戏目录、区服、会员及路由器管理 |
| `LoginActivity.java` | 百度官方网页登录，完成后回到原生管理界面 |
| `ApiClient.java` | HTTPS 请求、官方请求头、登录令牌交换及认证失败重试 |
| `SessionStore.java` | 使用 Android Keystore 的 AES-GCM 加密保存会话令牌 |
| `Repository.java` | 原生缓存、配置合并、接口数据裁剪和原子文件写入 |
| `GameRules.java` | 平台、搜索、设备类型、配置合并及加速消息规则 |
| `NativeUi.java` | 深浅色、间距、原生控件和交互状态 |

应用标识保持 `dongx.ybbrouter`，以便从初始网页版本覆盖升级并保留登录 Cookie。只在登录时显示 WebView；原生管理页不会加载或运行 H5 管理代码，也不使用 JavaScript bridge。

## 接口

依据 2026-11-07 实际读取的小米 WiFi 5.9.0 插件入口和游帮帮网页资源适配。以下为观察到的实现，并非官方公开兼容承诺。

接口根地址为 `https://ybb.baidu.com/api/v1/server/`。

| 方法 | 路径 | 用途 |
| --- | --- | --- |
| POST | `auth/token` | 使用当前应用内的百度登录 Cookie 换取管理令牌 |
| GET | `router/bind?brand=xiaomi` | 读取已绑定路由器 |
| GET | `router/device` | 读取连接、设备、插件版本和加速状态 |
| GET / POST | `router/config/game` | 读取 / 保存平台游戏配置与设备类型覆盖 |
| GET | `game/list?type=…` | 获取平台游戏目录 |
| GET | `gamelist/detail?game_id=…` | 获取区服及游戏详情 |
| POST | `router/message` | 发送 `start_speed` 或 `stop_speed` 指令 |
| GET | `user/info`、`goods`、`client/pop` | 账号展示、会员状态及可领取活动 |
| PATCH | `client/pop/{id}` | 用户主动确认后领取当前可用权益 |
| DELETE | `router/unbind/{id}` | 用户主动确认后解绑路由器 |
| GET | `user/logout`、`notice/list` | 退出登录 / 读取公告 |

认证要求 Bearer 令牌及稳定的 `X-Client-Cuid`。本机随机生成客户端标识，不使用硬件标识。请求使用与插件相同的渠道与协议版本头。

## 状态与安全

- 所有管理请求使用 HTTPS，只向固定的游帮帮域名发送账号 Cookie 和令牌，拒绝接口重定向。
- 不添加任意 URL、任意 JavaScript 或外部 Intent 注入入口；登录 Activity 不向其他应用导出。
- 令牌保存在 Keystore 加密的应用私有存储中。会话、目录和设备缓存均不进入云端备份或设备迁移。
- 用户信息只缓存显示所需的昵称与头像地址，游戏目录只缓存搜索和选择必需字段。
- 配置保存前重新读取服务端数据，只合并当前平台或指定 MAC 的修改，保留其他平台与未知字段。
- 发送启动指令前重新核对设备 IP 与 MAC、最新游戏配置、插件兼容性及其他设备的加速状态。
- 只有用户确认后才停止其他正在加速的设备；需要等待停止确认，再保存配置或启动目标设备。
- 不自动重试超时的修改请求，避免重复执行。只对服务端明确拒绝的认证请求重新登录后重试。
- 首页可见时定期读取状态，进入后台后停止轮询。命令提交与路由器实际生效分别展示，超时提示刷新核实。
- 登出清除应用自己的原生缓存、令牌、Cookie 与网页存储，不影响手机浏览器或小米 WiFi 的数据。

## 本地验证

10 项 JVM 测试覆盖配置合并不覆盖其他平台、旧线路清理、设备类型恢复自动识别、搜索、平台映射、插件版本兼容、原始类型保留、指令字段、缺失游戏拒绝和设备顺序稳定性。

真机验收应另行检查：冷启动缓存、游戏搜索与区服、账号页、断网、深浅色、Tab 焦点、返回导航，以及用户选定设备的实际启动与停止。通过构建和接口读取不代表已验证加速线路效果。


2026-11-07 已在用户连接的安卓手机上检查原生首页、17 台设备读取、PS5 的 595 款游戏目录、拼音搜索、当前游戏区服展示、账号会员页、页面返回、深浅色切换及 Tab 焦点。深浅色测试后恢复了原系统浅色设置。此轮界面验收未修改游戏配置；后续已通过原生界面验证 PS5 的实际加速启动。


0.2.1：加速计时使用服务器时间作为基准，结合单调时钟每秒更新，不依赖状态请求完成。启动与停止按钮统一为蓝底白字、固定尺寸；提交请求和等待路由器确认期间，当前按钮显示原生 ProgressBar，其他按钮的禁用状态保留白色文字。真机已观察到实际启动成功及启动、停止加载动画。
