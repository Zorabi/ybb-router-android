# 游帮帮路由助手

[![License: AGPL v3](https://img.shields.io/badge/License-AGPL_v3-blue.svg)](LICENSE)

直接管理小米路由器游帮帮加速插件的非官方原生安卓客户端。

## 功能

- 首页默认展示常用设备，支持切换全部设备、按名称或 IP 搜索，以及清理不再使用的常用记录。
- 选择设备的游戏与区服，启动、停止或切换加速设备；等待时显示加载动画，加速计时每秒更新。
- 按设备类型优先展示最近选择的 6 款游戏，支持单项移除、中文/英文/拼音搜索和本地目录缓存。
- 为设备设置本机别名、导出与恢复常用记录，支持查看会员状态、领取可用权益及管理路由器绑定。
- 原生展示服务公告，支持系统浅色、深色模式及键盘导航。

首页先显示本地记录并标明同步状态，后台仅更新变化的设备卡片，保留搜索输入和滚动位置；加速操作区分核对设备、发送指令和等待路由器确认。游戏搜索在本地完成，不需要每次切换页面重新下载网页。加速指令仍需通过游帮帮服务器下发，生效时间取决于官方服务和路由器响应。

## 安装与使用

1. 安装提供的 APK，打开「游帮帮路由助手」。已有旧版时直接覆盖安装，保留应用数据。
2. 使用原来绑定路由器的百度账号登录。登录通过百度官方授权网页完成，日常管理使用原生界面。
3. 在首页选择设备、游戏和区服，点击「开始加速」，等待路由器返回实际加速状态。

### 常用设备与游戏

- 首次添加常用设备时，切换到「全部设备」，点击设备右上角的更多按钮，选择「设为常用设备」；同一菜单可取消常用、设置本机别名或修改设备类型，搜索支持别名和原设备名，图标区分电脑、手机和游戏主机等设备类型。
- 常用设备按路由器与设备 MAC 识别。同一路由器下仅 IP 改变时，刷新后仍保留常用状态；MAC 改变后需将新设备重新设为常用。
- 「清理常用记录」列出未出现在当前列表中的设备，并显示已记录的名称、MAC 和最后出现时间。应用无法区分暂时离线与更换 MAC，请确认不再使用后再勾选移除；未发现的常用设备也会显示简卡和最后发现时间，暂不提供加速操作；更新前缺失的信息显示为未知。
- 点击设备卡片中的游戏，先显示最近常玩的最多 3 款及各自区服，通过「完整目录」浏览或搜索其他游戏。游戏成功保存后加入「最近使用」。点击右侧「移除」只清除该条记录，不改变当前加速配置；以后重新选择并保存时会再次加入。每款游戏成功保存的区服会单独记住，下次选择时优先展示并标记“上次使用”，点击确认后才会保存；区服已下线时需重新选择。

首次绑定或更换路由器仍需在小米 WiFi 的游帮帮插件中完成。修改正在加速的设备所用游戏与区服、切换加速设备时，应用会提示先停止当前加速，避免直接覆盖运行中的设置。

### 排队切换游戏

- 在设备卡片选择下一款游戏和区服。当前设备正在加速或已有停止操作时，应用会依次等待停止确认、保存新配置并自动开始加速，无需再手动点击开始。
- 等待期间再次选择游戏，只保留最新的待切换目标。启动指令已发出时，先等待确认，再处理后续选择；选择当前正在加速的同一游戏与区服不会重复停止。
- 首页显示待切换游戏与进度，可取消尚未发送的后续启动。已经执行的停止或配置保存不会撤销；停止失败、超时、设备离线或地址变化时中止切换并提示刷新。
- 排队任务仅保留在本次应用进程中，重启后不会补发。通过「游戏与线路」页面修改配置仍只保存设置，不自动启动设备。

### 备份与恢复

在「我的 → 备份与恢复」中导出 JSON 文件，或选择备份文件合并恢复。备份包含常用设备、设备别名、最近游戏和记住的区服，不包含登录令牌、Cookie、会员信息或服务端配置；恢复前按设备和游戏显示摘要，列出有冲突的设备或平台记录；勾选采用备份，未勾选保留本机整组记录，其他新记录正常合并。

备份中的设备名称与 MAC 属于本地偏好，请妥善保存。更换路由器后，原路由器的常用设备不会自动套用到新路由器。恢复不会直接修改路由器配置或启动加速。

「我的」提供会员状态、路由器管理、服务公告和帮助入口。会员开通与续费需使用游帮帮官方客户端，与原插件一致。退出登录保留路由器绑定；解绑后需要通过小米 WiFi 重新绑定。

## 兼容性

| 项目 | 条件 |
| --- | --- |
| 系统 | Android 6.0 及以上 |
| 登录 | 需要 Android System WebView 和可用的百度账号 |
| 路由器 | 已在小米 AX1800 上验证账号、设备与游戏目录读取；其他型号未验证 |
| 加速服务 | 取决于插件版本、设备类型、会员资格和官方线路可用性 |

本项目不提供加速节点或会员服务，使用的官方接口可能调整。首次下载目录、刷新设备状态和下发指令需要网络；本地缓存不能代替路由器当前的实际状态。

## 开发与测试

需要 JDK 17 或 21、Android SDK Platform 35 与 Build Tools 35.0.0。在 `local.properties` 中设置本机 SDK 路径，或配置 `ANDROID_HOME`。打包前按 [签名说明](docs/SIGNING.md) 配置固定密钥，以便覆盖升级保留应用数据。

```sh
./gradlew :app:assembleDebug :app:testDebugUnitTest :app:lintDebug
```

APK 输出到 `app/build/outputs/apk/debug/app-debug.apk`。安装到已授权调试的手机：

```sh
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

测试覆盖平台映射、搜索、插件兼容、配置合并、列表刷新、区服回显、偏好备份校验与日志路径脱敏。接口说明与安全设计见 [开发说明](docs/DEVELOPMENT.md)。

欢迎反馈复现步骤和经过脱敏的错误信息。贡献代码前请验证登录、页面返回、游戏与区服选择、断网重试及深浅色外观，勿提交账号、令牌或含个人信息的日志。
