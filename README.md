# 游帮帮路由助手

[![License: AGPL v3](https://img.shields.io/badge/License-AGPL_v3-blue.svg)](LICENSE)

直接管理小米路由器游帮帮加速插件的非官方原生安卓客户端。

## 功能

- 原生首页显示路由器连接状态、设备列表和加速状态，支持按名称或 IP 搜索设备。
- 选择设备的游戏与区服，启动、停止或切换加速设备；等待时显示加载动画，加速计时每秒更新。
- 按平台浏览游戏目录，支持中文、英文和拼音搜索；目录与已访问的区服信息保存在本地。
- 修改设备类型、查看账号会员信息、领取接口返回的可用会员权益及管理路由器绑定。
- 原生展示服务公告，支持系统浅色、深色模式及键盘导航。

首页优先显示上次同步的数据，再后台更新。游戏搜索在本地完成，不需要每次切换页面重新下载网页。加速指令仍需通过游帮帮服务器下发，生效时间取决于官方服务和路由器响应。

## 安装与使用

1. 安装提供的 APK，打开「游帮帮路由助手」。已有旧版时直接覆盖安装，保留应用数据。
2. 使用原来绑定路由器的百度账号登录。登录通过百度官方授权网页完成，日常管理使用原生界面。
3. 在首页选择设备、游戏和区服，点击「开始加速」，等待路由器返回实际加速状态。

首次绑定或更换路由器仍需在小米 WiFi 的游帮帮插件中完成。修改正在加速的设备所用游戏与区服、切换加速设备时，应用会提示先停止当前加速，避免直接覆盖运行中的设置。

「我的」提供会员状态、路由器管理、服务公告和帮助入口。会员开通与续费需使用游帮帮官方客户端，与原插件一致。退出登录保留路由器绑定；解绑后需要通过小米 WiFi 重新绑定。

## 兼容性

| 项目 | 条件 |
| --- | --- |
| 系统 | Android 6.0 及以上 |
| 登录 | 需要 Android System WebView 和可用的百度账号 |
| 路由器 | 已在小米 AX1800 上验证账号、设备与游戏目录读取；其他型号未验证 |
| 加速服务 | 取决于插件版本、设备类型、会员资格和官方线路可用性 |

本项目不提供加速节点或会员服务，使用的官方接口可能调整。首次下载目录、刷新设备状态和下发指令需要网络；本地缓存不能代替路由器当前的实际状态。

## 开发与测试

需要 JDK 17 或 21、Android SDK Platform 35 与 Build Tools 35.0.0。在 `local.properties` 中设置本机 SDK 路径，或配置 `ANDROID_HOME`。

```sh
./gradlew :app:assembleDebug :app:testDebugUnitTest :app:lintDebug
```

APK 输出到 `app/build/outputs/apk/debug/app-debug.apk`。安装到已授权调试的手机：

```sh
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

测试覆盖平台目录映射、中文/英文/拼音搜索、插件兼容规则、设备类型覆盖、配置合并和加速消息构造。接口说明与安全设计见 [开发说明](docs/DEVELOPMENT.md)。

欢迎反馈复现步骤和经过脱敏的错误信息。贡献代码前请验证登录、页面返回、游戏与区服选择、断网重试及深浅色外观，勿提交账号、令牌或含个人信息的日志。
